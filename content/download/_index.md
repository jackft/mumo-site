## Web app

Use mumo directly in your browser — no installation needed.

[Open webapp](/app/)

## Desktop (Electron)

Download the latest release for your platform from [GitHub Releases](https://github.com/jackft/mumo/releases).

## Source

```
git clone https://github.com/jackft/mumo.git
cd mumo
pnpm install
pnpm dev
```

Requires [Node.js](https://nodejs.org/) 18+ and [pnpm](https://pnpm.io/).
